# About Fissile Industries

Fissile Industries is a Minecraft mod project developed and maintained under **Hamster Systems**.

## Who owns Fissile Industries?

**Hamster Systems** is the organisation responsible for the Fissile Industries project and its official GitHub repositories.

The project website and wiki are maintained at [Fissile Industries Wiki](https://wiki.fissileindustries.com/).

## Official repositories

- [Fissile Industries mod](https://github.com/Hamster-Systems/Fissile-Industries) — main mod project.
- [Fissile Industries Documentation](https://github.com/Hamster-Systems/Fissile-Industries-Documentation) — wiki articles and reference information.
- [Fissile Industries Wiki website](https://github.com/Hamster-Systems/fissile-industries-wikipedia) — community website and wiki software.

## About the documentation

The wiki is intended to describe verified Fissile Industries features such as materials, ores, ingots, machines, chemistry and gameplay systems. A documentation page should not be treated as confirmation of a planned feature unless it says that feature is implemented.
